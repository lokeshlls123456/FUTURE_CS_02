# Project Overview

Phishing attacks are one of the most common cyber security threats used by attackers to steal sensitive information such as passwords, banking credentials, and personal data.

This project focuses on analyzing different email samples to identify phishing indicators such as suspicious sender addresses, fake domains, malicious links, urgency-based messages, and social engineering tactics.

The objective is to classify emails into Safe, Suspicious, or Phishing categories and create awareness about phishing attacks.

---

# Objective

* Detect phishing emails using manual analysis
* Identify phishing indicators
* Classify email threats based on risk
* Improve awareness about email-based attacks
* Recommend prevention techniques

# Methodology

The phishing detection process follows these steps:

1. Collect email samples
2. Analyze sender address
3. Check links and URLs
4. Review email content
5. Detect phishing indicators
6. Classify email risk
7. Document findings

# Common Phishing Indicators

* Spoofed sender email
* Suspicious links
* Grammar mistakes
* Urgent messages
* Threatening language
* Fake login pages

---

# Prevention Tips

* Verify sender identity
* Avoid clicking unknown links
* Enable Multi-Factor Authentication
* Use spam filters
* Report suspicious emails
* Check domain names carefully
